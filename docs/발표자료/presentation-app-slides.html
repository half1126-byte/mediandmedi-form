Chapter 07 / 이미 만든 것 — 미팅 DB SOLUTION 02
조직의 SOP 부재 — 미팅 영역 해결

미팅도 받아쓰기로
DB가 된다

"팀마다 기준이 다르다"는 문제 중 미팅 영역을 먼저 해결했습니다.
Notion AI 받아쓰기 + 자동 요약 + 거래처 양방향 연결로
모든 미팅이 동일한 형식으로 기록됩니다.

받아쓰기가 끝나면 AI가 핵심 결정사항·액션 아이템을 자동 분리합니다.

STAGE 01 · 미팅 시작 전
새 미팅 페이지 생성 (1분)
제목 · 일자 거래처 선택 참석자 태그 주요 안건
↓
STAGE 02 · 미팅 중
/음성 메모 → 자동 받아쓰기 (한국어)
노트북 마이크 모바일 앱 가능 자동 동기화
↓
STAGE 03 · 미팅 직후
/AI → 지침대로 자동 요약 (1~2분)
핵심 결정사항 액션 아이템 담당자/마감일
↓
STAGE 04 · 자동 연결
거래처 DB에 자동 표시 + 담당자 알림
양방향 Relation @멘션 알림
BEFORE
미팅 후 정리에 30~60분
기록 담당자 노트북 / 메모장 / 카톡 — 흩어짐
공유 정리해서 슬랙에 다시 붙여넣기
거래처 연결 사람이 거래처 페이지 찾아 메모 붙여넣기
액션 추적 담당자 기억에만 의존 — 누락 빈번
AFTER
미팅 후 4분이면 끝
기록 /음성메모 → 한국어 자동 받아쓰기
정리 /AI → 등록된 지침대로 자동 요약
거래처 연결 거래처 선택만 하면 양방향 자동 동기화
액션 추적 @담당자 멘션 → 자동 알림 + DB 누적
"

기준이 없으면 사람마다 다르게 일한다.
기준을 만들어도 도구가 강제하지 않으면
또 흩어진다.

받아쓰기 + AI 요약 지침은
기준을 도구에 박아 넣는 방식이다.
