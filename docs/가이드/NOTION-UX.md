# 노션 DB UI/UX 개선 가이드

API로 자동 적용된 것: 아이콘, 설명
아래는 노션에서 직접 설정해야 하는 항목입니다. (~15분)

---

## 1. 팀별 업무 DB — 칸반 보드 만들기 (가장 중요)

팀원들이 가장 많이 쓸 DB. 테이블보다 **칸반 보드**가 훨씬 보기 좋습니다.

1. `팀별 업무` DB 열기
2. 좌측 상단 "테이블" 옆 `+` 클릭
3. **"보드"** 선택
4. 그룹 기준: **상태** (대기 / 진행중 / 완료)
5. 뷰 이름: `상태별 보드`

→ 업무 카드를 드래그해서 대기 → 진행중 → 완료로 옮길 수 있음

**추가 뷰: 팀별 보드**
1. 다시 `+` 클릭 → "보드"
2. 그룹 기준: **팀** (카페팀 / 블로그팀 / 디자인팀)
3. 뷰 이름: `팀별 보드`

---

## 2. 팀별 업무 — 셀렉트 색상 변경

1. `팀별 업무` DB에서 아무 행의 **팀** 셀 클릭
2. 각 옵션 옆 `···` 클릭 → 색상 변경:
   - 카페팀 → **주황**
   - 블로그팀 → **파랑**
   - 디자인팀 → **보라**

3. **상태** 셀도 동일:
   - 대기 → **회색**
   - 진행중 → **파랑**
   - 완료 → **초록**

---

## 3. 신규거래처 DB — 뷰 정리

### 기본 테이블 뷰에서 보이는 속성 정리

속성이 33개라 테이블이 너무 넓음. 핵심만 보이게 설정:

1. `신규거래처` DB 열기
2. 우측 상단 `···` → "속성" (또는 테이블 헤더 우클릭 → "속성 숨기기")
3. 아래 속성만 **보이기**, 나머지는 **숨기기**:

**기본 테이블에 보일 속성 (10개):**
- 이름 (치과명)
- 원장명
- 지역(시도)
- 지역(구군)
- 개원예정일
- 주력진료
- 계약서비스
- 월계약금
- 예산범위
- 제출일

나머지 23개는 숨기기. 행을 클릭하면 전체 속성이 다 보이니까 괜찮음.

### 캘린더 뷰 추가 (개원예정일 기준)

1. 테이블 옆 `+` → **"캘린더"**
2. 날짜 기준: **개원예정일**
3. 뷰 이름: `개원 일정`

→ 이번 달, 다음 달 개원 예정인 거래처가 달력에 표시됨

### 셀렉트 색상

**예산범위:**
- 100만원 이하 → 회색
- 100~200만원 → 갈색
- 200~300만원 → 노랑
- 300~500만원 → 초록
- 500~700만원 → 파랑
- 700~1000만원 → 보라
- 1000만원 이상 → 빨강

**주차:**
- 가능 → 초록
- 불가 → 빨강
- 발렛 → 파랑
- 기타 → 회색

**지역(시도):**
- 서울특별시 → 파랑
- 경기도 → 초록
- (나머지는 자유)

## 4. 계약변경 DB — 정렬

1. `계약변경` DB 열기
2. 정렬 추가: **제출일** 내림차순 (최신이 위로)
3. 속성 보이기:
   - 이름 (치과명)
   - 원장명
   - 현재상품
   - 추가상품
   - 축소상품
   - 변경사유
   - 제출일

---

## 5. 팀 페이지에 링크드 뷰 넣기

### 카페팀 페이지
1. `팀 스페이스` → `카페팀` 페이지 열기
2. `/링크된` → `팀별 업무` 선택
3. 뷰 타입: **보드** (상태별)
4. **필터 추가: 팀 = 카페팀**
5. 뷰 이름: `카페팀 업무`

### 블로그팀, 디자인팀도 동일

---

## 6. 경영진 페이지

1. `경영진` 페이지 열기
2. 제목 아래에 텍스트: `거래처 현황 대시보드`

3. `/링크된` → `신규거래처` → 테이블
   - 보이는 속성: 치과명, 원장명, 지역(시도), 개원예정일, 계약서비스, 월계약금
   - 정렬: 제출일 내림차순
   - 뷰 이름: `최근 신규거래처`

4. `/링크된` → `계약변경` → 테이블
   - 정렬: 제출일 내림차순
   - 뷰 이름: `최근 계약변경`

5. `/링크된` → `팀별 업무` → 보드 (상태별)
   - 뷰 이름: `전체 업무 현황`

## 적용 전/후 비교

### Before
- 아이콘 없음, 설명 없음
- 셀렉트 전부 회색
- 신규거래처 33개 속성이 한 줄에 다 보임
- 팀별 업무가 테이블 (업무 관리에 부적합)
- 뷰 1개 (기본 테이블만)

### After
- 🏥📋🔄🏢 아이콘으로 한눈에 구분
- 셀렉트 색상으로 팀/상태/예산 즉시 인식
- 신규거래처 핵심 10개만 테이블에, 나머지는 클릭 시 표시
- 팀별 업무 칸반 보드 (드래그로 상태 변경)
- 캘린더 뷰 (개원일정)
- 팀 페이지에서 자기 업무만 필터링
