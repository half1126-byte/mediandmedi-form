## 2. 자동 vs 수동 구분 (중요)

### ✅ 완전 자동으로 작동
| 작업 | 동작 |
|------|------|
| AI 받아쓰기 | 녹음 → 자동 텍스트 변환 (한국어 지원) |
| 지침대로 요약 | `/AI 요약` 명령 시 등록한 지침 형식대로 정리 |
| 거래처 ↔ 미팅 양방향 연결 | 미팅에서 거래처 선택 → 거래처 페이지에 미팅 자동 표시 |

### ⚠️ 수동 또는 추가 설정 필요
| 작업 | 처리 방법 |
|------|----------|
| 담당자 알림 | `@담당자명` 멘션 직접 입력 (5초) |
| 거래처 DB 속성 업데이트 (계약상태, 메모 등) | 사람이 직접 수정 |
| 액션 아이템 → 별도 업무 DB 연동 | Notion Automation 설정 또는 수동 입력 |

## 3. 표준 미팅 워크플로우

### Step 1. 미팅 시작 전 (1분)

1. 미팅 기록 DB 접속
2. 우측 상단 **+ 새로 만들기** 클릭
3. 메타데이터 입력:

| 컬럼 | 입력 예시 |
|------|----------|
| 미팅 제목 | `왕편한플란트치과 6월 진료일정 미팅` |
| 일자 | 미팅 날짜 |
| 거래처 | 드롭다운에서 해당 치과 선택 (Relation) |
| 미팅 유형 | 신규개원 / 계약변경 / 진료일정 / 정기 / 긴급 중 1개 |
| 상태 | `시작 전` 자동 |
| 참석자(내부) | 우리 팀원 People 태그 |
| 참석자(외부) | 원장님/외부 관계자 이름 텍스트 |
| 주요 안건 | 미팅 전 미리 작성 (간단히) |

### Step 2. 미팅 중 — 받아쓰기 시작 (10초)

#### 노트북에서
1. 페이지 본문 영역 클릭
2. `/` 입력 → **음성 메모** 선택
3. 마이크 권한 허용 → 🔴 녹음 시작
4. 미팅 종료 시 ⏹ 정지 → 자동 받아쓰기 (한국어)

#### 모바일 (외근/방문 시)
1. Notion 모바일 앱에서 같은 페이지 열기
2. 페이지 하단 + 버튼 → 음성 메모
3. 녹음 → 정지 → 자동 동기화

### Step 3. 미팅 후 — AI 요약 (1~2분)

받아쓰기 완료된 페이지에서:

1. 본문에서 `/` 입력 → **AI** → **AI에게 묻기** 클릭
2. 입력: `회의 요약 지침대로 정리해 줘`
   - 또는 더 구체적으로: `핵심 결정사항만 체크리스트로 뽑아 줘`
3. 결과 검토 → 컬럼에 복사:
   - `핵심 결정사항` 컬럼에 → ✅로 시작하는 결정 항목들
   - `액션 아이템` 컬럼에 → 팀별 todo 리스트

### Step 4. 후속 처리 (30초)

1. 액션 아이템 컬럼 안에서 담당자 이름 앞에 **@멘션** 추가
   - 예: `@김민지 임플란트 프로모션 랜딩페이지 5/25까지`
   - 자동으로 김민지에게 알림 발송됨
2. 다음 미팅 컬럼에 차회 미팅 일자 입력
3. 상태를 `완료`로 변경
4. 필요 시 거래처 DB 속성 직접 업데이트 (계약상태, 활성여부 등)

## 4. 자주 쓰는 AI 프롬프트

| 목적 | 프롬프트 |
|------|----------|
| 핵심 정리 | `이 회의의 핵심 결정사항을 3줄로 요약해 줘` |
| 액션 추출 | `이 회의에서 나온 todo를 담당자/마감일과 함께 표로 정리해 줘` |
| 다음 미팅 안건 | `이번 회의에서 미해결로 남은 안건을 정리해 줘` |
| 회의록 작성 | `이 받아쓰기를 정식 회의록 형식으로 다시 써 줘` |
| 이메일 초안 | `이 회의 결과를 거래처 원장님께 보낼 이메일로 정리해 줘` |
| 슬랙 공유 | `이 결정사항을 팀 슬랙에 공유할 짧은 메시지로 만들어 줘` |

## 5. 받아쓰기 지침 (요약)

### 미팅 전 페이지 만들기
- 메타데이터 (제목/일자/거래처/유형/참석자) **반드시 입력**
- 주요 안건 미리 작성하면 AI 요약 품질 향상

### 받아쓰기 환경
- ⚠️ **개인정보 주의**: 환자 본명/주민번호/진단명은 받아쓰기 후 마스킹 처리
- 마이크 가까이 (1m 이내)
- 조용한 공간 권장
- 1시간 이내 녹음 권장 (긴 녹음은 분할)

### 모바일 사용 시
- 미팅 시작 전 모바일에서 페이지 미리 열기
- 와이파이/데이터 연결 확인
- 노트북과 자동 동기화됨

## 6. 알림 받는 방법

Notion은 다음 경우에만 알림을 보냅니다:

| 알림 트리거 | 효과 |
|-----------|------|
| `@사용자명` 멘션 | 즉시 알림 |
| `참석자(내부)` 컬럼에 사람 추가 | 그 사람에게 알림 |
| `담당자` 컬럼에 사람 지정 | 그 사람에게 알림 |
| 페이지 단순 생성/수정 | ❌ 알림 안 감 |

**가장 확실한 방법: 액션 아이템에 `@담당자` 멘션 추가**

## 7. 자동화 추가 설정 (선택, 추후 필요 시)

운영해 보시고 필요하다 판단되면 다음 자동화 설정 가능:

### A. 미팅 생성 시 거래처 담당마케터 자동 알림
- 미팅에 거래처 Relation 선택 → 그 거래처의 담당마케터에게 자동 멘션
- Notion Automation 사용 (Plus 이상)

### B. 액션 아이템 → 업무 DB 자동 추가
- 액션 아이템 텍스트 분석 → 별도 "업무" DB에 자동 행 생성
- Notion Database Automation

### C. 미팅 완료 시 Slack 자동 공유
- 상태 `완료` → Slack 채널에 핵심 결정사항 자동 게시
- Slack 통합 + Automation

> 위 자동화 원하시면 별도 요청해 주세요. 30분~1시간 내 설정 가능.

## 8. 자주 묻는 질문

### Q1. 미팅 페이지에 거래처를 선택하면 거래처 DB가 자동으로 최신화되나요?
**A.** 부분만 자동입니다.
- ✅ 거래처 페이지의 `미팅 기록` 항목에 미팅이 자동 추가됨
- ❌ 거래처의 다른 속성 (계약상태, 메모, 활성여부 등)은 **사람이 직접 업데이트** 필요

### Q2. 받아쓰기가 끝나면 담당자한테 자동으로 알림이 가나요?
**A.** 자동으로는 안 갑니다. 액션 아이템에 `@담당자` 멘션을 직접 추가해야 알림이 갑니다.

### Q3. AI 요약이 마음에 안 들어요. 어떻게 개선하나요?
**A.** AI 요약 지침 페이지(https://www.notion.so/35c9a82db9c481a89c70f27fb647bc20)를 직접 수정하세요. 구체적이고 짧은 지시가 긴 지시보다 효과적입니다.

### Q4. 받아쓰기 한도가 있나요?
**A.** Notion Plus + AI 추가 가입 시 무제한. AI 미가입 시 월 약 20회 제한. 한도 초과 시 휴대폰 녹음 → 파일 첨부 후 다음 달에 받아쓰기.

### Q5. 마이크 권한이 안 떠요.
**A.** 브라우저 설정 → 사이트 권한 → notion.so 마이크 허용

### Q6. 받아쓰기 한국어 인식이 부정확해요.
**A.** 마이크와 가까이, 조용한 환경에서 녹음. 외부 마이크 사용 시 더 정확.

### Q7. 미팅 한 건당 얼마나 시간이 걸리나요?
**A.** 표준 흐름 기준:
- 페이지 만들기: 1분
- 미팅 진행: 미팅 시간 그대로
- AI 요약 + 정리: 2~3분
- 후속 멘션 + 마감일: 30초
- **추가 부담: 약 4분**

## 9. 주의사항

### 개인정보 처리
- 환자 본명, 주민번호, 진단명, 처방 내역 등 민감 정보는 받아쓰기 후 마스킹
- 사용 후 노션 페이지 권한 확인 (외부 공유 금지)

### 거래처 페이지 권한
- 거래처 DB는 팀 내부용 → 외부 공유 절대 금지
- 미팅 페이지 단독 공유도 거래처 정보가 노출되므로 주의

### 백업
- Notion 자체 백업이 있으나, 중요 미팅은 별도 보관 권장
- 받아쓰기 원본 (`녹음 파일` 컬럼)에 m4a 파일 첨부 보관
