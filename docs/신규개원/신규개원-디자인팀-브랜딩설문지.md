# 신규개원 디자인팀 브랜딩(BI/CI) 설문지

> 디자인팀이 **로고·BI/CI·브랜드 영상** 제작에 필요한 정보를 받는 설문지입니다.
> 첫 적용 사례: **서울이도치과**. 다른 거래처엔 치과명만 바꿔 재사용하세요.
>
> 📌 질문 정본 인덱스: [신규개원-질문-합본.md](신규개원-질문-합본.md)
> 성격: [브랜딩 인터뷰](신규개원-브랜딩-인터뷰.md)가 원장님의 **'왜/어떤 치과'**(전략·감성)를 다룬다면, 이 설문지는 **디자인 실행**(로고 타입·컬러 시스템·납품 범위·영상 제작 옵션) 중심입니다. 겹치는 항목은 인터뷰 결과를 옮겨 적으면 됩니다.

```
치과명: ____________________   원장님: ____________   작성일: 2026-__-__   담당(디자인): ____________
```

## 1. BI / CI (브랜드 아이덴티티)

### 1-1. 브랜드 방향성

**Q1.** 「치과명」 네이밍의 의미나 유래를 알려주세요. *(작명 배경, 담고 싶었던 메시지, 한자/영문 표기가 있다면 함께)*

> **A1.**

**Q2.** 브랜드 슬로건이나 캐치프레이즈를 이미 가지고 계신가요? 없다면 이번 작업에 포함이 필요하신가요?

> **A2.**

**Q3.** 브랜드를 통해 전달하고 싶은 **핵심 키워드 3가지**를 꼽으신다면? *(예: 신뢰감 / 프리미엄 / 친근함 / 모던 / 전문성 / 정직함 / 따뜻함)*

> **A3.**

**Q4.** 타깃 환자층은 어떻게 설정하고 계신가요?
- 주 타깃 연령대:
- 성별 비중:
- 소득/라이프스타일:
- 주요 거주 권역:

> **A4.**

**Q5.** 경쟁 병원으로 인식하는 곳이 있으신가요? 그 병원 대비 **차별화 포인트**는?

> **A5.**

**Q6.** 인상 깊었거나 벤치마킹하고 싶은 브랜드를 알려주세요. *(치과·병원뿐 아니라 일반 브랜드도 환영)*
- 시각 레퍼런스 3~5개
- 각 레퍼런스에서 좋았던 점

> **A6.**

**Q7.** 반대로 **피하고 싶은 스타일/톤**이 있으신가요? *(예: 너무 차가운 / 너무 귀여운 / 흔한 의료 이미지 / 올드한 느낌)*

> **A7.**

### 1-2. 로고 신규 제작 — 컨셉 발굴

**Q8.** 로고에 반드시 담겼으면 하는 의미나 스토리가 있으신가요? *(예: "치과는 무서운 곳이 아니다", "오래도록 함께하는 주치의")*

> **A8.**

**Q9.** 로고 타입 선호도가 있으신가요?
- [ ] 워드마크형 (글자 중심, 예: COCA-COLA)
- [ ] 심볼+워드마크 결합형 (예: 스타벅스)
- [ ] 심볼 중심형 (예: 애플, 나이키)
- [ ] 이니셜형 (예: LG, HP)
- [ ] 아직 결정 못함 — 시안 제안받고 싶음

> **A9.**

**Q10.** 로고 표기를 어떻게 가져가시겠습니까?
- [ ] 한글 단독 (예: 서울이도치과)
- [ ] 영문 단독 (예: Seoul Ido Dental Clinic)
- [ ] 한글+영문 병기
- [ ] 한자 포함

> **A10.**

**Q11.** 영문 표기를 쓴다면 **정확한 스펠링**을 알려주세요. *(예: Seoul Ido / Seoul-Ido / SEOULIDO — 모든 자료에 일관 적용)*

> **A11.**

**Q12.** 로고에 들어가면 좋겠다 싶은 **시각 요소·모티브**가 있으신가요? *(치아 형상·이니셜·지역 상징·자연·기하 도형 / "치아는 직접 안 들어갔으면" 같은 반대 의견도 OK)*

> **A12.**

### 1-3. 로고 신규 제작 — 컬러 시스템

**Q13.** 선호하는 컬러 계열이 있으신가요?
- [ ] 블루 계열 (신뢰, 전문성)
- [ ] 그린 계열 (자연, 안정)
- [ ] 뉴트럴/베이지 (프리미엄, 따뜻함)
- [ ] 모노톤 (블랙/그레이, 모던)
- [ ] 기타 (___)
- [ ] 추천받고 싶음

> **A13.**

**Q14.** 절대 피하고 싶은 컬러가 있으신가요? *(예: 빨강은 위협적 / 노랑은 저렴해 보임)*

> **A14.**

**Q15.** **인테리어 마감재·컬러 톤**을 미리 공유받을 수 있을까요? *(BI 컬러와 공간 컬러의 조화가 중요 — 도면/무드보드 사전 공유)*

> **A15.**

### 1-4. 로고 제작 진행 방식

**Q16.** 1차 시안 제시 개수는 몇 개를 희망하시나요? *(통상 3~5개 제시 → 1개 방향성 선택 → 디벨롭)*

> **A16.**

**Q17.** 시안별 **수정 가능 횟수** 합의. *(통상 방향성 선택 후 수정 3회 / 이상은 추가 협의)*

> **A17.**

**Q18.** 시안 컨펌 **의사결정권자**는 누구신가요?
- [ ] 원장님 단독
- [ ] 공동 원장 협의 (___명)
- [ ] 기타 (배우자·컨설턴트 등): ___

> **A18.**

**Q19.** 로고 **최종 납품 데드라인**이 있으신가요? *(개원 역산 — 인쇄물·사인물 발주 일정 고려해 D-day 합의)*

> **A19.**

### 1-5. 브랜드 적용 범위 (BI 확장)

**Q20.** 브랜드 가이드 매뉴얼 활용 계획은?
- [ ] 내부 직원 교육·일관성 관리용
- [ ] 외부 협력사 배포용 (인쇄소·사인업체)
- [ ] 양쪽 모두

> **A20.**

**Q21.** 응용 디자인 가이드 적용 **우선순위**는?
- [ ] 명함·처방전·동의서 등 기본 서식류
- [ ] 리플렛·포스터·현수막 등 홍보물
- [ ] 진료 안내문·환자 교육 자료
- [ ] 봉투·진료 차트 표지 등
- [ ] 기타 (___)

> **A21.**

**Q22.** 사인물(외부 간판·내부 사이니지·진료실 표시)은 BI 작업과 어떻게 연계할까요? *(견적상 별도 항목 / 통상 사인 업체에 BI 가이드 전달)*

> **A22.**

**Q23.** 유니폼·굿즈(환자 증정용)·진료실 환경 그래픽 작업이 필요하신가요?

> **A23.**

**Q24.** 명함/봉투 등 인쇄물의 **실제 인쇄 제작비는 별도**라는 점 인지 확인. *(견적서 명시 사항)*

## 2. 브랜드 영상

### 2-1. 영상 컨셉 & 활용

**Q25.** 영상으로 전달하고 싶은 **핵심 메시지**는? *(의료진 전문성 / 따뜻한 분위기 / 최신 장비 / 정직한 진료 철학)*

> **A25.**

**Q26.** 인상 깊었던 병원·브랜드 **영상 레퍼런스**가 있으신가요? *(유튜브/SNS 링크)*

> **A26.**

**Q27.** 영상 주요 활용 채널은? *(복수 선택)*

- [ ] 병원 내 대기실 모니터
- [ ] 기타 (___)

> **A27.**

**Q28.** 견적 기준 제작 예정 영상 항목 — 우선순위·추가 요청 확인.
