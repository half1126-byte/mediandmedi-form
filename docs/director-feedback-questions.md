## Q1. 인테리어 컨셉 입력 형식

### 현재 상태
- Step3 (시설/장비) 에 위치
- 자유 텍스트 1줄 입력
- 플레이스홀더 예시: "모던, 따뜻한 우드톤, 아이 친화적"

### 변경 후
- Step4 (브랜딩 & 철학)으로 이동

### 선택지

**A) 자유 텍스트 1줄 (현재 유지)**
- 형식: `<input type="text">`, 한 줄
- 장점: 입력 부담 적음
- 단점: 길게 쓰고 싶은 경우 불편

**B) 자유 텍스트 여러 줄 (textarea로 변경)**
- 형식: `<textarea rows={3}>`, 여러 줄 가능
- 장점: 컨셉/스타일/타겟 분위기 등 풍부하게 작성 가능
- 단점: 디자인팀이 핵심만 추출하는 수고 증가

**C) 옵션 다중 선택 + 자유 텍스트**
- 옵션: 모던/내추럴 우드/화이트 미니멀/럭셔리/키즈 친화/감성/정보 미정 등 (체크박스)
- + 추가 설명 자유 텍스트 (선택)
- 장점: 디자인팀이 빠르게 방향 파악
- 단점: 옵션 정의에 시간 들어감, 옵션에 없는 컨셉 표현 어려움

**권장:** **B (textarea)** — 디자인 작업에는 풍부한 묘사가 더 유용. 단순 키워드만 적어도 됨.

## Q2. 장비 항목 변경 (인터뷰 자료)

### 현재 상태 (14개)
```
CT(CBCT), 구강스캐너, 디지털X선, CAD/CAM,
레이저, 현미경, 임플란트 네비게이션,
교정 시뮬레이션, 구강카메라, 에어플로우,
N2O 장비, 성장진단장비, 골격분석검사기, 성장판검사기
```

### 결정 필요 사항

이사님께서 언급하신 "인터뷰 자료 내용"이 어떤 자료인지 확인 필요합니다.

### 선택지

**A) 인터뷰 자료를 보내주세요**
- 카카오톡/이메일로 인터뷰 자료(PPT/문서) 전달
- 그걸 보고 정확히 반영
- 가장 정확하나 자료 전달 대기 시간 발생

**B) 추정해서 작성 후 검토 요청**
- 일반적으로 치과 인터뷰에서 자주 묻는 장비 기준 (예시 30개) 작성
- 이사님께서 보고 가감
- 빠르나 누락/오류 가능성 있음

**C) 현재 14개 → 더 상세한 분류로 확장 + 인터뷰 자료 받으면 추가 보강**
- 현재 14개 + 자주 누락되는 항목 5~10개 추가 (스케일링 장비, 무통마취기, 자동멸균기, 디지털 인상 시스템 등)
- 인터뷰 자료 받으면 그 후 보강
- 빠르고 확장 가능

**권장:** **A (인터뷰 자료 전달)** — 정확도가 중요. 자료가 즉시 어렵다면 C 임시 적용.

## Q3. 로고 파일 첨부 방식

### 현재 상태
- `hasProfilePhoto` 체크박스만 있음 (보유 여부만)
- 실제 파일은 별도 카카오톡 등으로 받는 것으로 추정

### 신규 요청
- 로고 파일 보유 체크박스
- 첨부파일 업로드 (이사님 의견: "넣을 수 있으면 좋겠습니다")

### 선택지

**A) 체크박스만 추가, 파일은 카카오톡으로 받기**
- 구현: 5분
- 장점: 바로 가능, 추가 인프라 불필요
- 단점: 원장님이 카톡 별도 전송 필요 (UX 단절)

**B) Vercel Blob에 자동 업로드 + Notion에 URL 저장**
- 구현: 1~1.5시간 + Vercel Blob 환경변수 설정
- 장점: 폼 안에서 완결, Notion에서 바로 미리보기
- 단점: Vercel Blob 사용량 발생 (무료 1GB/월), 실수로 잘못된 파일 업로드 위험
- 비용: 월 100건 × 평균 2MB = 200MB → **무료 티어 내**

**C) Notion API 직접 업로드 (Notion 자체 파일 호스팅)**
- 구현: 2시간 (Notion 파일 업로드 API는 2024년 신규 추가)
- 장점: 파일이 Notion 안에 자체 보관
- 단점: API 안정성 검증 안 됨, 파일 크기 제한 5MB

**권장:** **B (Vercel Blob)** — 가장 안정적이고 UX가 매끄러움. 단, 다음 사항 결정 필요:
- 허용 파일 형식: `.png, .jpg, .svg, .ai, .pdf` 중 어떤 것?
- 최대 크기: 10MB로 제한?

## Q4. 소아교정 하위 항목

### 이사님 작성 내용
```
□ 소아교정 (□ 프리올소 □ 펜듈럼 □ 페이스마스크 □ 기타)
```

### 결정 필요 사항

3가지 + 기타 외에 누락된 자주 쓰는 항목이 있는지 확인 필요합니다.

### 일반적으로 사용되는 소아교정 장치 (참고)

| 장치 | 용도 |
|------|------|
| 프리올소 (Prealigner) | 단순 교정 전 단계 |
| 펜듈럼 (Pendulum) | 어금니 후방 이동 |
| 페이스마스크 (Face Mask) | 상악 전방 이동 |
| MARA / 헤드기어 | 골격 교정 |
| RPE (Rapid Palatal Expander) | 상악 확장 |
| 트윈블록 | 하악 전방 유도 |
| 마이오브레이스 | 근기능 교정 |
| 인비절라인 퍼스트 | 투명교정 (소아용) |

### 선택지

**A) 이사님 작성 그대로 (프리올소/펜듈럼/페이스마스크/기타)**
- 가장 빠름, 이사님 의도 정확 반영
- 누락 가능성 있으나 "기타"로 커버

**B) 이사님 3개 + 자주 쓰는 5개 추가 (총 8개)**
- 더 정확한 데이터 수집 가능
- 디자인팀/마케팅팀에서 활용도 높음

**C) "기타" 선택 시 자유 텍스트 입력**
- 3개 + 기타 + 기타 선택 시 입력칸 펼쳐짐
- A안 + UX 보강

**권장:** **A 또는 C** — 이사님 의도가 명확하시면 A. "기타"에 어떤 게 자주 들어올지 궁금하시면 C.

## Q5. 메가젠 "애니원 ST" 표기

### 이사님 작성 원문
```
메가젠 □ 블루 다이아몬드 □ 애니원, □ST, □ 스트라우만, ...
```

### 모호한 부분

- `애니원, □ST` 의 쉼표가 **두 개 항목으로 구분**인지, **한 모델 "애니원 ST"** 인지 불명확

### 메가젠 실제 모델 (참고)
- AnyOne (애니원) — 메가젠의 대표 모델
- AnyRidge (애니릿지)
- BlueDiamond (블루 다이아몬드)
- ST는 메가젠 단독 모델로는 일반적이지 않음 (다른 회사의 제품일 가능성)

### 선택지

**A) 두 개 항목: "애니원" + "ST" (별도)**
- 메가젠: 블루 다이아몬드 / 애니원 / ST (총 3개)
- "ST"는 어떤 회사 제품인지 추가 확인 필요

**B) 한 항목: "애니원 ST"**
- 메가젠: 블루 다이아몬드 / 애니원 ST (총 2개)
- 애니원의 ST 라인을 의미할 수 있음

**C) 메가젠 모델 다시 정리 (실제 라인업 기준)**
- 메가젠: 블루 다이아몬드 / 애니원 / 애니릿지 / 기타
- 가장 정확하나 이사님 원본과 다름

**권장:** **이사님 직접 확인 필요** — 모델 라인업이 영업/계약과 직결되어 추측 위험

## Q6. 리뷰 증정선물 표시 트리거 조건

### 이사님 작성 원문
```
- 네이버리뷰/카톡채널 추가시 증정선물 작성칸 추가
```

### 모호한 부분

"네이버리뷰/카톡채널 추가시"의 "추가"가 어떤 행동인지 명확하지 않습니다.

### 가능한 해석

**해석 A: 마케팅 채널에서 "네이버 리뷰" 또는 "카카오톡 채널"을 선택했을 때**
- Step5에 `desiredChannels` (원하는 채널) 또는 신설 채널 옵션
- 위 두 개 중 하나라도 체크 → 증정선물 입력칸 표시

**해석 B: 계약 서비스에서 "영수증 리뷰" / "예약 리뷰" / "카카오톡 채널 운영" 등을 추가할 때**
- Step6에서 해당 서비스를 계약에 포함 → 증정선물 입력칸 표시

**해석 C: 네이버리뷰/카톡채널 운영을 "신규 추가" (별도 옵션)**
- "이번에 새로 시작하시는 채널" 체크박스에 네이버리뷰/카톡채널이 있고, 체크 시 증정선물 입력

### 선택지 (해석에 따른 구현 방향)

**A) 마케팅 채널 옵션 선택 트리거**
- Step5의 `desiredChannels`에 "네이버 영수증 리뷰", "네이버 예약 리뷰", "카카오톡 채널" 항목 추가
- 이 중 하나라도 선택 시 → "리뷰 작성/채널 친구 추가 시 어떤 증정선물을 주실 예정인가요?" 입력칸 표시

**B) Step6 계약 서비스 트리거**
- 계약 서비스에 "영수증 리뷰", "예약 리뷰" 등이 포함되면 → 증정선물 입력칸 표시
- 계약과 직결되어 있으나 폼 구조상 Step6에서 묻기는 위치가 어색

**C) 독립 질문 (트리거 없이 항상 표시)**
- "리뷰 이벤트 / 카톡 친구 증정 선물이 있다면 알려주세요" 항상 표시
- 가장 단순, 트리거 로직 불필요

### 권장: A (마케팅 채널 옵션 트리거)

이사님 의도가 "**해당 채널을 운영할 때**"인 것으로 보임. Step5에서 채널 선택 시 자연스럽게 증정선물 질문 흐름.
