무승인 생성 금지

🎙 녹음으로 시작

  1. Notion 음성 메모 또는 녹음 파일 저장
  2. 받아쓰기·요약으로 논의 내용을 구조화
  3. 결정사항과 사내 실행 항목 후보를 추출
  4. 담당자가 원문과 비교해 액션 아이템을 확정

✍️ 수기로 시작

  1. 미팅 본문은 형식 없이 자유롭게 작성 가능
  2. 담당자가 결정·요청·검토·아이디어를 구분
  3. 실행이 확정된 항목만 액션 아이템으로 이동
  4. 업무 하나당 한 줄로 정리하고 모호한 표현 제거

사람이 내용을 검토한 뒤 미팅 상태=완료 + 업무 생성 요청=체크
미팅 담당자 화면

녹음·수기 내용을 검토하고 업무 생성을 승인합니다

미팅 상태, 관련 거래처, 담당자와 실행 문장을 확인한 뒤 생성 요청을 체크합니다.

STEP 1

미팅 기록 수집

녹음 또는 수기 본문과 거래처·참석자·미팅 담당자를 한 미팅 페이지에 모읍니다.

2단계

필요한 내용만 정리

인사말·반복·단순 아이디어를 빼고 실제로 해야 할 문장만 남깁니다.

STEP 3

사람 검토·승인

업무명·대상 거래처·실행 범위를 확인합니다. 자동 요약만으로는 생성되지 않습니다.

STEP 4

안전 조건 검사

완료 상태, 생성 요청, 거래처 1곳, 유효 액션을 확인하고 중복 업무를 검사합니다.

STEP 5

팀 분류

내용을 마케팅·바이럴·디자인·웹 업무로 분류합니다. 미지원·모호 항목은 생성하지 않습니다.

6단계

담당자 정하기

마케팅 업무는 거래처DB의 담당마케터에게 먼저 배정합니다. 그 정보를 읽을 수 없을 때만 미팅 담당자 1명에게 배정하며, 담당자가 없거나 여러 명이면 멈춥니다.

7단계

(신)업무DB에 만들기

업무명·병원·담당팀·담당자·상태를 저장하고 원래 미팅도 함께 연결합니다.

생성 결과

승인된 할 일이 담당자의 업무로 배정됩니다

업무명, 병원, 담당팀, 담당자와 원래 미팅이 (신)업무DB에 함께 기록됩니다.

STEP 8

직원 실행

업무 페이지의 필터된 체크리스트에서 실행하고 결과 링크·캡처·접수번호 등 증빙을 남깁니다.

9단계

진행률 자동 계산

체크리스트에서 완료한 개수를 세어 진행률을 자동으로 올립니다.

STEP 10

업무 완료·종료

체크리스트가 1개 이상이고 모두 완료되면 업무상태를 완료로 바꾸고 종료일을 기록합니다.

오류 시 동작: 거래처 없음·복수 연결, 담당자 불명확, 동일 업무 중복, 지원하지 않는 팀이면 업무를 만들지 않습니다. 원인을 업무 생성 오류에 기록하고 운영자가 수정한 뒤 다시 승인합니다.

08 / 외주작가

받은 임상 자료를
빠짐없이 원고로 연결합니다

병원이 준 자료는 임의로 줄이지 않습니다. 작가는 전체 자료를 확인해 최대한 활용하고, 사용할 수 없는 자료가 있으면 이유를 남깁니다. 회사는 병원별 요청사항을 작업 전에 정리합니다.

기존 방식

작가마다 자료 사용 방식이 다름

사진을 줄이는 기준과 원고·사진의 배열 방식이 달라 누락 여부를 확인하기 어려웠습니다.

발생 문제

사진 누락·순서 혼선·재작업

원장님이 준 자료가 원고에서 빠지거나, 워드와 사진 파일의 순서가 달라 게시 단계에서 다시 확인해야 했습니다.

새 기준

전체 확인 후 최대한 활용

전달받은 자료는 임의로 줄이지 않습니다. 워드와 별도 사진 파일에 같은 순서와 번호를 사용합니다.

바이럴팀 새 지침 반영
예외 처리

제외할 때는 이유를 보고

중복·식별 불가·개인정보·품질·광고 심의 문제가 있는 자료는 담당자 확인 후 제외합니다.

임의 제외 금지
WRITER 1

외주 원고 판정

업무 유형이 정보성·임상 블로그 원고인지 확인하고 내부 작성·외주작가·대행업체를 구분합니다.

WRITER 2

계약·배정량 확인

거래처 계약 건수, 현재 월 작업량, 이월 건수, 계약 종료 여부를 기준표와 대조합니다.

WRITER 3

자료·병원 요청 확인

MNM이 누락·오전달·명백한 중복을 확인하고, 원장님 선호사항과 강조할 진료 방향을 공유 폴더에 정리합니다.

WRITER 4

작가 배정

작가 마스터의 전문 분야·담당 거래처·가용 건수와 개인 시트를 확인해 정확히 한 명에게 배정합니다.

WRITER 5

작업 지시

원자료 링크, 거래처, 원고 유형, 건수, 마감일, 가이드, 병원별 요청사항과 결과물 폴더를 하나의 업무에 연결합니다.

WRITER 6

전체 확인·원고 작성

작가가 ZIP을 풀고 모든 사진과 케이스를 확인합니다. 특별한 문제가 없으면 자료를 임의로 줄이지 않고 최대한 활용합니다.

WRITER 7

사진 순서·번호 정리

워드에 실제 게시 순서대로 사진을 넣고, 별도 사진 파일도 같은 순서로 1-1, 1-2… / 2-1, 2-2…처럼 번호를 붙입니다.

WRITER 8

납품·예외 보고

지정 폴더에 원고와 사진을 올립니다. 제외하거나 작업할 수 없는 자료는 삭제·추측하지 않고 파일명과 이유를 담당자에게 알립니다.

WRITER 9

승인·발행

최종 승인된 원고만 발행하고 발행 링크와 완료일을 기록합니다. 재작업은 별도 상태로 추적합니다.

WRITER 10

월말 대조·정산

계약표·중앙 배정표·작가 개인 시트·발행 건수를 대조해 누락·과다·오기를 해결한 뒤 정산합니다.

누가 무엇을 하나요?

회사와 작가가 맡는 일

회사는 쓸 수 있는 자료와 고객 소통을 맡고, 작가는 받은 자료로 원고를 만드는 일을 맡습니다.

구분MNM 내부 책임외주작가 책임금지·예외
자료수령·누락·오전달·명백한 중복 확인다운로드·압축 해제 후 전체 이미지·케이스 확인특별한 문제가 없는 자료를 임의로 줄이거나 제외하지 않음
고객 대응자료 부족·오류 시 거래처에 재요청작업 중 발견한 문제를 내부 담당자에게 보고작가가 거래처와 직접 해결하거나 추측하지 않음
제작가이드·마감·결과물 폴더·병원별 요청사항 제공임상 해석·기획·원고 작성·워드 사진 삽입·별도 사진 번호 정리·납품치과나 내부 담당자에게 작가 편의를 위한 PPT 재가공을 요구하지 않음
관리계약·배정·발행·정산 DB와 과거 사용 이력 관리본인 배정 업무의 진행 상태와 결과물 관리작가에게 회사 전체 DB 정리나 과거 전수대조를 전가하지 않음
원고 1건의 작업 범위자료 전체 확인 → 케이스 구분 → 사용할 순서 결정 → 임상 내용 파악 → 환자에게 필요한 정보 작성 → 워드에 사진 삽입 → 별도 사진 번호 정리 → 지정 폴더 제출까지 포함합니다. 목표는 정보량만 늘리는 것이 아니라, 이해하기 좋은 정보를 충분히 제공해 검색 노출과 상담 전환 가능성을 높이는 것입니다.
사진 번호 예시1번 케이스 → 1-1, 1-2, 1-3, 1-4
2번 케이스 → 2-1, 2-2, 2-3, 2-4
워드에 들어간 순서와 별도 사진 파일의 번호가 반드시 같아야 합니다.
운영 안정화이 기준은 모든 임상 외주작가에게 동일하게 적용합니다. 9월까지 누락과 재작업이 줄었는지, 작가 작업시간이 지나치게 늘지 않았는지 확인한 뒤 공통 기준을 보완합니다.
제외·반려·중단 조건: 중복 사진, 환자·증례 구분 불가, 개인정보 노출, 사용할 수 없는 품질, 의료광고상 사용 곤란, 비정상적인 대량 파일, 계약과 배정 건수 불일치, 담당 작가 미확정, 누락·이름 오류가 있으면 임의로 삭제·추측하거나 발행·정산으로 넘기지 않습니다. 파일명과 이유를 담당자에게 알리고 내부 확인 후 처리합니다.
