Chapter 01 / DX란?DEFINITION
Digital Transformation · 디지털 전환

DX는 도구를
디지털로 바꾸는 일이다

DX(Digital Transformation)는 단순히 "컴퓨터 쓰기"가 아닙니다.
종이 차트 → 엑셀, 손 계산 → 자동 합산, 카톡 → 노션처럼
업무가 흘러가는 길을 디지털로 다시 까는 작업입니다.

🚗

마차에서 자동차로

마차 시대: 말이 끄는 만큼만 간다. 사람이 모든 걸 직접 한다. 종이, 손글씨, 구두 전달.

자동차 시대(DX): 같은 거리도 10배 빨리. 사람은 운전만, 엔진은 알아서. 노션, 시트, 자동 보고서.

→ DX는 "사람이 시키는 일을 도구가 빠르게 처리"하는 구조입니다.

DX 예시 01완료된 사례
우리가 이미 도달한 곳

청구 시트 → 자동 보고서

예전에는 매월 청구서를 손으로 정리해서 보고서를 만들었습니다. 지금은 시트에 입력만 하면 자동으로 거래처별 보고서가 생성됩니다.

같은 일에 시간이 1/10로 줄었습니다.

DX 예시 02진행 중
아직 가야 할 곳

카톡 받아쓰기 → 폼 입력

아직도 거래처 미팅이나 변경 요청은 카톡으로 들어옵니다. 마케터가 받아 적고, 정리하고, 노션에 옮깁니다.

이걸 폼으로 바꾸면 마케터의 받아쓰기 시간이 사라집니다.

Chapter 02 / AX란?NEXT STEP
AI Transformation · 인공지능 전환

AX는 판단까지
AI에게 넘기는 일이다

AX(AI Transformation)는 DX의 다음 단계입니다.
DX가 도구를 빠르게 만들었다면, AX는 도구가 "알아서" 판단하고 정리하게 만듭니다.
받아쓰기, 요약, 분류, 추천, 예측. 이 모든 게 사람 손을 떠납니다.

🤖

자동차에서 자율주행으로

자동차(DX): 길은 있지만 운전은 사람이. 어디로 갈지, 언제 멈출지 직접 결정.

자율주행(AX): AI가 길을 보고, 신호를 읽고, 결정한다. 사람은 "어디로 가고 싶은지"만 정하면 됨.

→ AX는 "사람의 시간이 단순 처리에서 의사결정으로 옮겨가는" 구조입니다.

  • 추적 = 알림 자동 + 패턴 분석

DX는 업무가 빨라지는 일이다.
AX는 업무가 사라지는 일이다.

안 사라지는 업무에 사람이 매달려 있으면, 그 회사는 곧 뒤처진다.

Chapter 07 / AX 첫걸음SOLUTION 02
Stage 02 · 처리를 AI로

미팅도 AI가
받아 적고 정리한다

이게 바로 AX의 첫 사례입니다.
받아쓰기, 요약, 액션 추출까지 — 사람이 하던 일을 AI가 처리, 사람은 검토만.
자동차가 자율주행으로 넘어가는 그 순간을 우리도 통과하고 있습니다.

DX 단계 (예전)
미팅 후 정리에 30~60분
기록담당자 노트북 / 메모장 / 카톡
정리사람이 기억으로 회의록 작성
공유정리해서 슬랙에 다시 붙여넣기
추적담당자 기억에만 의존 — 누락 빈번
AX 단계 (현재)
미팅 후 4분이면 끝
기록/음성메모 → AI 한국어 받아쓰기
정리/AI → 등록된 지침대로 자동 요약
공유거래처 DB에 양방향 자동 연결
추적@담당자 멘션 → 자동 알림 + DB 누적
✨

여기서부터가 진짜 AX다

AI 받아쓰기: 23분 미팅 → 1분 안에 정리. 사람의 정리 시간이 사라집니다.

AI 자동 분류: "핵심 결정", "액션 아이템", "다음 미팅 안건"으로 자동 분리.

AI 담당자 분배: 액션 아이템에서 마케팅팀/디자인팀/콘텐츠팀 자동 식별.

→ 회사가 AX를 처음으로 일상에서 쓰기 시작한 지점입니다.

"

AI는 사람을 대체하지 않는다.
사람이 더 중요한 일에 시간을 쓰게 만든다.

받아쓰기에서 해방된 마케터는 전략을 짠다.
